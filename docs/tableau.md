# Tableau 工作簿说明

`tableau/taobao_user_behavior.twb` 保留原项目的 12 个分析视图和看板布局。工作簿使用本地 MySQL 结果表，不包含完整原始数据或可脱机运行的数据提取。

## 连接与刷新

1. 按 `sql/` 中的编号创建原始表、导入数据并生成分析结果表，数据库名为 `taobao_user_operations`。
2. 使用 Tableau Desktop 打开工作簿，在数据源中将 MySQL 主机、端口和用户名改为自己的本地配置。默认占位配置为 `localhost:3306`、`analytics_user`，密码自行输入。
3. 确认 MySQL 驱动可用，刷新数据源及字段元数据。公开版结果字段与工作簿引用保持一致。
4. 打开“看板”。GitHub 不能直接运行 `.twb`，浏览仓库时可以查看 `assets/` 中基于聚合结果重新生成的图表。

## 公开版整理

- 清除作者与设备指纹、旧图表缩略图及无关的本机连接身份信息。
- 将留存字段统一为 `retention_rate`，漏斗人数字段统一为 `funnel_users`。
- 修正商品与品类热度工作表的标题，标明展示的是按浏览量筛选的前20项。
- 比例计算使用聚合后的分子和分母：`SUM([buy])/SUM([pv])`，以及 `(SUM([cart])+SUM([fav]))/SUM([pv])`；浏览次数为零时返回空值。
- 购买路径视图改称购买行为组合，避免将是否发生过行为解释成严格时间顺序。
- RF 视图命名与实际使用的两维模型一致。公开 SQL 对相同购买次数规定排序依据，刷新后分层比例以公开规则为准。

工作簿原始版本为 Tableau 2026.3。公开版已完成 XML 结构、字段引用和公式修改检查；在自己的 MySQL 实例连接后，应通过 Tableau 刷新和渲染确认布局。仓库静态图直接由已核对的聚合统计绘制，不依赖旧缓存图像。
